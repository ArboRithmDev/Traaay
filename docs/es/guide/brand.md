# Identidad Visual y Diseño

La identidad de marca de Traaay se basa en **La Arquitectura de 3 Estratos**, reflejada en las 3 "a" de su nombre: **Tr<span class="traaay-a1">a</span><span class="traaay-a2">a</span><span class="traaay-a3">a</span>y**.

---

## Filosofía: Los Tres Estratos

Cada estrato encarna un nivel de control con su color distintivo:

| Estrato | Nombre | Código Hex | Rol y Significado |
| :--- | :--- | :--- | :--- |
| **Estrato 1** | **Glacier Cyan** | `#38BDF8` | **Claridad y Separación**: El separador plegable que alivia la carga mental. |
| **Estrato 2** | **Electric Blue** | `#3B82F6` | **Control y Conciencia**: Detección del Notch y dominio del espacio en pantalla. |
| **Estrato 3** | **Soft Mint** | `#34D399` | **Fluidez y Acceso**: La paleta flotante e interacciones directas sin fricción. |

El sistema visual reposa sobre una base oscura profunda, **Dark Obsidian** (`#0F1117`), garantizando un contraste óptimo y una armonía natural con el Modo Oscuro de macOS.

---

## El Wordmark: Tr**a** **a** **a** y

El logotipo textual utiliza una tipografía moderna del sistema (SF Pro Display o Inter) con espaciado condensado (`letter-spacing: -0.03em`), enmarcando las 3 vocales cromáticas entre letras de anclaje blancas:

```
Tr [a : Cyan] [a : Blue] [a : Mint] y
```

## Icono de la Aplicación macOS

El icono de Traaay adopta el squircle oficial de Apple con las siguientes especificaciones de diseño:
- **Fondo**: Gradiente vertical Dark Obsidian (`#1A1D27` hacia `#090A0E`) con ribete metálico superior.
- **Símbolo central**: Tres cápsulas horizontales redondeadas en cascada con degradados luminosos y suave reflejo cristalino.
- **Sombra proyectada**: Doble capa de elevación nativa acorde con los estándares de macOS Sequoia y Sonoma.
